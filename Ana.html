Ana alcaraz

Engine programer • ui programmer

Throughout this project, I worked as a part of the Code team, taking on two distinct roles as development progressed.Before the game development itself began, I worked alongside a teammate to build the base engine that the entire project would be built upon.During the first half of the project, I was fully focused on engine programming, working to build our custom enigne. I developed the lighting system including spot ,point and directional lights, shadow system linked with the directional light, prefab management system, an automatic backup system and the build generation pipeline, including separating the engine from the game so we could generate a standalone excutable.Once the engine rached a stable state, I transitioned to UI programming. Using Noesis and Lua, I implemented in-game interface systems, including the mask tutorial popups, the interactive button indicator, the enemy lock-on display and the tutorial system. I also developed a UI queue manager to handle element priority and prevent multiple elements from overlapping on screen simultaneously.
