Toni llovera

ui programmer • vfx programmer • technical artist

As a UI Programmer, I was responsible for the full implementation of the game’s user interface systems using NoesisGUI (XAML) within our custom engine. I developed all major UI screens, including the HUD, Main Menu, Pause Menu, Settings (audio and graphics), Loading Screens, Splash Screen, and Title Screen, ensuring both functionality and integration with gameplay systems.I implemented all underlying logic for UI behavior and game flow, including dynamic HUD updates (health, stamina, mask changes), save system feedback, and state-driven transitions such as when to display or hide UI elements. I also programmed all settings functionality, such as fullscreen toggling and audio controls.To enhance user experience, I created interactive UI animations (fade-ins, fade-outs, button feedback) and developed multiple screen-space visual effects. These included contextual vignette effects, tightly integrated with gameplay events to reinforce player feedback.Additionally, I implemented a custom post-processing component within the engine, developing and integrating multiple shader-based effects such as Depth of Field, Fog, Blur, Vignette, Color Grading, and Bloom. I also configured and balanced these effects across different levels, ensuring visual consistency and performance.Part of my work involved collaborating on the development of a custom CanvasComponent for UI rendering within the engine & its Lua functions to modify its valors. Throughout production, I iterated on both UI systems and flow logic to ensure that all elements behaved correctly and responded accurately to gameplay conditions.
